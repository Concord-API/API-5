# Objetivo do Produto

Permitir que o usuário descubra, em minutos e com procedência auditável, **como um tema
jurídico está sendo decidido** no TJSP, no TJRJ e no TJMG, com uma medida objetiva do quanto
esse entendimento está consolidado — em vez de garimpar um acórdão de cada vez.

## Três compromissos

- **O resultado é um tema, não uma lista de processos.** Um buscador devolve documentos; o Ratio devolve o padrão.
- **Todo número declara sua fonte, data de extração e escopo.** O usuário cita o que lê aqui, então um número sem base não é informação.
- **Quando o dado não existe, o produto diz isso.** Ele nunca preenche a lacuna com um valor plausível.

## Para quem é

Uma única persona: o **usuário**. O Ratio é uma aplicação local, rodando na intranet do
usuário. A mesma pessoa precisa das duas coisas que o produto faz — *sustentar* uma posição
(a tese se mantém, quanto costuma ser arbitrado, qual acórdão citar) e *decidir* de forma
consistente (o que o tribunal já pacificou, se as câmaras divergem, se um precedente
vinculante se aplica).
